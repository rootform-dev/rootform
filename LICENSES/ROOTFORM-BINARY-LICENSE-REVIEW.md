# Rootform Binary License — legal review required

**Status: not approved for public distribution.**

Rootform executable files are proprietary and are not licensed under the
repository's Apache License 2.0. A qualified lawyer must approve final Rootform
Binary License terms before any executable release becomes public.

Until approval:

- binary release assets remain private development candidates;
- no file or metadata may describe a binary as Apache-2.0;
- every private candidate archive must include this notice as
  `ROOTFORM-BINARY-LICENSE.txt`;
- every release page must state that the candidate is proprietary,
  unsupported, private, and not for redistribution;
- checksums, SBOMs, and third-party notices remain required.

Legal review must settle at least permitted use, copying, redistribution,
reverse engineering where legally controllable, warranty, liability,
termination, governing law, evaluation duration if any, and trademark terms.

This file defines a boundary and release blocker only. It is not final license
text.
