# Third-party notices

Release archives must include a generated dependency inventory, complete
required license texts, and notices for every shipped dependency and asset.
Those release-specific files live beside each release manifest under
`releases/<version>/` and inside each archive.

Repository examples reference Terraform providers by source address but do not
copy provider executables or provider source. Provider, service, and product
names remain trademarks of their owners.

No Rootform binary is licensed by this file. Binary terms are separate and must
be included in every binary archive.
